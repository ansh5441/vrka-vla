# Integration Map (`vrka-vla`)

| Boundary / Interface | Producer → Consumer | Protocol / Mechanism | Verification & Safety Contract |
| :-- | :-- | :-- | :-- |
| **TLA+ / PlusCal Formal Verification** | [`specs/horizon_lease/vrka_horizon_lease.tla`](../../specs/horizon_lease/vrka_horizon_lease.tla) → `tla2tools.jar` | [`scripts/verify_specs.sh`](../../scripts/verify_specs.sh), `make tla-check`, `make verify-specs` | Translates PlusCal (`pcal.trans`) and runs headless TLC (`tlc2.TLC -workers auto`); fails closed on any parse error, deadlock, or violation of `SafetyNoCollision`, `CBFBarrierInvariant`, or `SeqlockNoTornRead` ([`scripts/test_verify_specs.sh`](../../scripts/test_verify_specs.sh)). |
| **Shared-Memory Seqlock IPC (`vrka-shm`)** | `vrka_proposer` (`25 Hz` Python) → `vrka-rt` (`500 Hz` Rust) | POSIX `mmap` shared memory with `#[repr(C, align(64))]` Seqlock header & slot (`vrka-abi`) | Writer sets odd `shm_seq` before payload write and even `shm_seq` on commit (`WriteBegin` → `WriteCommit`). Reader checks even `shm_seq`, `seq_before == seq_after`, `.is_finite()`, and `shm_chunk_ttl > 0`; discards torn reads in `O(1)` without spinning (`RT-06`, [ADR 003](../adr/003-wait-free-seqlock-ipc.md)). |
| **500 Hz CBF-QP Safety Filter (`vrka-cbf`)** | `vrka-rt` candidate velocity (`v_cand`) → Actuator command (`ctrl_vel`) | `#![no_std]` pure Rust projection / bounded-iteration C-FFI QP solver | Enforces discrete/continuous braking-distance barrier `robot_pos + v + BrakingDistance(v) <= EffectiveObstaclePos` on every 500 Hz tick; falls back to `DECEL_FALLBACK` (`ctrl_ttl = 1`) and `STANCE_LOCK` (`ctrl_vel = 0` when `ctrl_ttl = 0`) (`RT-04`, `RT-08`, [ADR 004](../adr/004-cbf-qp-safety-shield.md)). |
| **Wolf-Pack Swarm UDP Leases (`vrka-swarm`)** | Peer quadrupeds ↔ `vrka-swarm` / `vrka-rt` (`UDP :9500`) | Linux `io_uring` pre-registered buffers + IEEE 1588 PTPv2 timestamps | Validates packet size, spatial security token ([ADR 002](../adr/002-spatial-security-tokens.md)), monotonic sequence, and `peer_lease_ttl \in 1..MAX_HORIZON_TTL`. Tightens `EffectiveObstaclePos = min(peer_pos, THREAT_POS)` while `peer_lease_ttl > 0` (`RT-17`, `RT-18`, [ADR 005](../adr/005-multi-agent-pack-leases.md)). |
| **Kernel Jitter & Flight Recorder (`vrka-ebpf`)** | `vrka-rt` (`500 Hz` spine) → Cold-path recorder & `aya-rs` eBPF | Lock-free `#[repr(C, align(64))]` ring buffer + kernel tracepoints | Records every mode transition, CBF clamp, and lease expiry with `0` heap allocations; alerts if scheduling jitter exceeds `MAX_JITTER_BUDGET_NS = 50_000` (`50 µs`) (`RT-12`, `RT-19`). |
| **Physics & Chaos Simulation (`vrka-sim`)** | `vrka-rt` / `vrka-swarm` ↔ `libmujoco` (`500 Hz`) | Safe Rust RAII FFI adapter (`crates/vrka-sim`) | Deterministic 500 Hz closed-loop simulation with fault injection for proposer stalls, torn Seqlock frames, and peer UDP packet drops (`RT-13`, `RT-15`). |
